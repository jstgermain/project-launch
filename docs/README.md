# Project documentation

This directory is the operating record for `project-launch`.

- [`ARCHITECTURE.md`](ARCHITECTURE.md) describes the current skill architecture and information flow.
- [`PROJECT_LAUNCH.md`](PROJECT_LAUNCH.md) is the single checklist for implementation, validation, and publication.
- [`now.md`](now.md) contains only current work.
- [`decisions.md`](decisions.md) records durable decisions and why they were made.
- [`notes.md`](notes.md) records reusable maintenance gotchas.

Keep these files aligned, but do not duplicate their jobs. Architecture describes the current system, decisions explain why, the checklist tracks remaining work, and `now.md` states what is active.
